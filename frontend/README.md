# Frontend UI

Simple HTML/CSS/JavaScript frontend for MiniShop.

---

# Features

- Product Grid
- AI Product Assistant
- Dynamic Product Rendering
- Query Autocomplete
- Responsive UI

---

# Run Frontend

cd frontend

python3 -m http.server 5500

Open:
http://127.0.0.1:5500

---

Frontend UI
